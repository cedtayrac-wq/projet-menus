📱 Application Mobile Gratuite (Android & iPhone)

Cette application est conçue avec la technologie PWA (Progressive Web App) : elle est 100% gratuite, sans publicité, fonctionne hors-ligne et s'installe directement sur l'écran d'accueil de votre smartphone comme une application native.

🤖 Sur Android (Chrome) :
  1. Ouvrez l'application dans Chrome sur votre téléphone.
  2. Appuyez sur le bouton "📲 Installer l'App" en haut de l'écran (ou sur le menu ⋮ en haut à droite $\rightarrow$ "Ajouter à l'écran d'accueil" / "Installer l'application").
  3. Utilisez ensuite le bouton "Envoyer vers l'app Google Keep" pour transférer votre liste de courses en 1 tap vers votre application Google Keep !
🍎 Sur iPhone / iPad (Safari) :
  1. Ouvrez l'application dans Safari.
  2. Appuyez sur le bouton Partager (carré avec une flèche vers le haut en bas de l'écran).
  3. Choisissez "Sur l'écran d'accueil".
